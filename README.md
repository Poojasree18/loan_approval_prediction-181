Loan Approval Prediction with MLflow

This project uses a Random Forest Classifier to predict loan approval and MLflow to track the machine learning experiment.

Technologies Used
Python
Pandas
NumPy
Scikit-learn
MLflow
Project Overview

A simulated loan dataset is created using information such as income, credit score, age, and loan amount. The data is divided into training and testing sets, and a Random Forest model is trained to predict loan approval.

MLflow is used to track the model's parameters, accuracy, and trained model artifact.

MLflow Tracking

The experiment is named Loan_Approval_Tracking.

The following are tracked:

Model parameters
Test accuracy
Trained Random Forest model
How to Run

Install the required Python libraries, run the project, and start the MLflow UI to view the experiment results and model details.

Result

The project displays the test accuracy after training and stores the model information in MLflow.

Note: This project uses simulated data and is intended for educational purposes and MLflow experiment-tracking practice.
